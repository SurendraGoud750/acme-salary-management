# 3–5 minute demo script

1. **Dashboard (30 sec):** Explain headcount, country/department distribution, and salary summaries grouped by currency.
2. **Directory (60 sec):** Search employee number/name, filter by country and department, sort and paginate.
3. **Employee profile (45 sec):** Show current salary and historical records.
4. **Salary change (60 sec):** Enter a valid amount, currency, frequency, and effective date; submit and confirm the old period is retained.
5. **Quality (45 sec):** Show test commands, 10,000-record seed, and the architecture/trade-off docs.
6. **Close (20 sec):** Explain deliberately excluded payroll/tax and FX conversion.

Use synthetic data only. Do not expose secrets or real salary data in the recording.
